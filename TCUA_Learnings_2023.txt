1. To see the information on a class or business object, in the Business Modeler IDE right-click the object
and choose Open in UML Editor.

2. To see the inheritance relationships the object has to other objects, in the UML Editor right-click the
object and choose Show → Inheritance to Root

3. Secondary business objects can be converted to primary business objects using the Business
Modeler IDE by right-clicking the secondary business object in the Business Objects view of the
Advanced perspective and choosing Convert to primary

4. Use the TC_write_syslog API to write warnings to the syslog, and use the TC_report_serious_error API
to write errors to the syslog. To use these functions, include the tc.h file
